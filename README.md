# 🎓 SVU Live Lectures Dashboard (Modern Web Interface)

![SVU Dashboard Banner] <img width="1311" height="554" alt="svulancher" src="https://github.com/user-attachments/assets/b95d0a41-584e-4b46-afd8-f5f8dbc31567" />


An upgraded, highly optimized, and modern web interface for the Syrian Virtual University (SVU) live lectures player. Designed to fix the outdated legacy UI, providing students with a sleek, real-time dashboard to track, filter, and join their online lectures seamlessly.

---

## ✨ Key Features

- 🌙 Modern Dark UI: A refined dark-themed interface designed for eye comfort during long study sessions.
- 📊 Real-Time Status Counters: Instant visual tracking for active (جارية الآن), upcoming (لم تبدأ), and completed (منتهية) lectures.
- 🔍 Advanced Filtering: Filter lectures effortlessly by subject, academic program, or current status.
- 📅 Interactive Schedule Table: Clean tabular view displaying lecture timing, course titles, professors' names, and real-time status badges.
- ⚡ Lightweight & Fast: Pure HTML/CSS/JS architecture with zero heavy framework bloat for maximum performance.

---

## 🛠️ Built With

- HTML5 - Semantic structure and layout
- CSS3 - Custom dark mode themes, Flexbox/Grid layouts, and CSS variables
- JavaScript (ES6+) - Dynamic DOM manipulation and filter logic
